# 聚合通行证 · yvhan

Android 端多平台聚合登录助手：一个 App 完成多个平台的扫码/短信登录、消息聚合与云端同步。

## 功能

- **四 Tab 主界面**：账号库 / 扫码登录 / 消息 / 设置（Miuix 澎湃 OS 风格 UI）
- **多平台接入**：森空岛、米游社、库街区（KuroBBS）扫码确认与手机号验证码登录
- **扫码登录**：相机扫码识别平台 → 确认登录，结果进消息并推送通知
- **消息聚合**：多平台消息统一列表与详情，登录成功通知
- **WebDAV 多文件双向同步**：每条数据独立 `records/<id>.json`，删除双向传播；双端同条修改标冲突，逐条人工选择保留本地或云端；数据以 PBKDF2 + AES-GCM 加密后上传，云端只有密文
- **细节**：摄像头仅在扫码页停稳且前台时启动；二级页纯水平推拉转场；首屏始终为主页面（新装可先配置同步恢复数据）

## 构建

- JDK 21、Gradle 9.8+、compileSdk 37
- `gradle :app:assembleDebug`（或在 Android Studio 中直接打开运行）

## 隐私说明

- 代码中不含任何账号 token / 密码硬编码，登录凭证仅保存在本机
- 云同步内容在本机加密后上传，服务端只有密文
- 各平台请求头中的设备标识为运行时生成的随机值（保持协议格式），不携带作者设备信息
